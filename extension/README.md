# VSBlox

Roblox Studio as a panel inside VS Code (Windows).

Run **VSBlox: Open Roblox Studio Panel** from the command palette. Studio launches if
it isn't running, then docks into the panel without its title bar. Close the panel
to give Studio its normal window back.

Settings:
- `vsblox.studioSize`: `fit` or a fixed size like `1920x1080`
- `vsblox.hideTitleBar`: hide Studio's title bar while docked (default on)
- `vsblox.autoLaunchStudio`: launch Studio when the panel opens (default on)
